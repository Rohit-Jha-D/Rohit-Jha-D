## 🛠️ Step 1: Create Your GitHub Special Profile Repository

1. Log in to your GitHub account: [https://github.com](https://github.com)
2. Create a **New Repository**.
3. Name the repository **`Rohit-Jha-D`** (It MUST match your exact GitHub username `Rohit-Jha-D`).
   > 💡 You will see a special banner: *"You found a secret! Rohit-Jha-D/Rohit-Jha-D is a ✨special✨ repository that you can use to add a README.md to your GitHub profile."*
4. Select **Public** (Do NOT make it Private).
5. Check **Initialize this repository with a README**.
6. Click **Create repository**.

## 📤 Step 2: Upload Files to the Repository

You can upload the files directly via GitHub Web or using Git CLI:

### Option A: Via GitHub Web Interface
1. Open your new `Rohit-Jha-D/Rohit-Jha-D` repository.
2. Click **Add file** ➔ **Upload files**.
3. Drag & drop the following files into the repository:
   - `README.md`
   - `header-banner.svg`
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/` (folder containing `banner.jpg`)
4. Click **Commit changes**.

### Option B: Via Git Command Line
```bash
git clone https://github.com/Rohit-Jha-D/Rohit-Jha-D.git
cd Rohit-Jha-D

# Copy all generated files into this folder

git add .
git commit -m "feat: setup senior UI/UX profile readme and interactive portfolio"
git push origin main
```

## 🌐 Step 3: Enable Free Live Web Portfolio on GitHub Pages

1. Go to your `Rohit-Jha-D/Rohit-Jha-D` repository on GitHub.
2. Click **Settings** ➔ **Pages** (on the left menu).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` branch, `/ (root)` folder.
4. Click **Save**.
5. Within 1-2 minutes, your live portfolio will be published at:  
   👉 **`https://rohit-jha-d.github.io/`** (or `https://rohit-jha-d.github.io/Rohit-Jha-D/`)
